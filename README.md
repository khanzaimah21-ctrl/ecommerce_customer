# Ecommerce Customer EDA Dashboard

Exploratory Data Analysis of Ecommerce Customers to understand what drives Yearly Amount Spent.

## Key Findings
- Length of Membership is the strongest driver (0.81 correlation)
- Time on App (0.50) matters more than Time on Website (0.00)
- Longer membership = More spending

## How to Run
python -m streamlit run app.py

## Files
- app.py - Streamlit Dashboard
- ecommerce_customer EDA.ipynb - EDA Notebook
- ecommerce_customers.csv - Dataset
